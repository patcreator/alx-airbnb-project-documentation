
# Airbnb Clone Backend – Use Case Diagram

## Overview
This use case diagram visualizes the interactions between different actors and the Airbnb Clone backend system. It illustrates how users and external services interact with the system to perform core functionalities such as user authentication, property management, booking, and payments.

## Actors
- Guest: Users who search for properties and make bookings.
- Host: Users who create and manage property listings.
- Admin: System administrators who manage users, listings, and bookings.
- Payment Gateway: External service responsible for handling payments and payouts.

## Key Use Cases
- User registration and authentication
- Property listing management
- Property search and filtering
- Booking creation and cancellation
- Payment processing and host payouts
- Reviews and ratings
- Notifications
- Administrative management
