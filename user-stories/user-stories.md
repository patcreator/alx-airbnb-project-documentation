# Airbnb Clone Backend – User Stories

## User Stories

1. As a guest, I want to be able to register an account so that I can book properties and manage my reservations.

2. As a guest, I want to search for available properties by location and filters so that I can find a place that meets my needs.

3. As a guest, I want to book a property for specific dates so that I can stay at the selected location.

4. As a guest, I want to make secure payments so that my booking can be confirmed.

5. As a host, I want to create property listings so that guests can view and book my properties.

6. As a host, I want to edit or delete my property listings so that I can keep my listings accurate and up to date.

7. As a host, I want to receive payouts after successful bookings so that I can earn income from my properties.

8. As a guest, I want to leave reviews and ratings for properties so that I can share my experience with other users.

9. As a host, I want to respond to guest reviews so that I can communicate with guests and manage my reputation.

10. As an admin, I want to manage users, listings, and bookings so that the platform operates safely and efficiently.
